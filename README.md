# anrbucin

Halaman web interaktif satu file (HTML + CSS + JS murni) berisi kata-kata dengan animasi ketik, tombol "Sayang/Ga", efek hati, dan tombol lanjut ke WhatsApp. Proyek iseng tahun 2022.

## Menjalankan

Buka `index.html` langsung di browser, atau host statis apa saja (GitHub Pages, Netlify).
